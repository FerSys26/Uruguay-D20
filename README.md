# Uruguay D20

Sitio web informativo y estático para descubrir Uruguay y sus 19 departamentos, su cultura y las comunidades uruguayas en el exterior (Departamento 20).

## Tecnología
- HTML, CSS y JavaScript sin frameworks.
- Sin backend, base de datos, formularios ni panel de administración.
- Compatible con GitHub Pages y Cloudflare Pages.
- Diseño adaptable a móviles, tabletas y escritorio.
- Selector de idioma: español, catalán, inglés, francés, ruso y alemán.

## Publicación en Cloudflare Pages
- Repositorio: `FerSys26/Uruguay-D20`
- Rama: `main`
- Comando de compilación: dejar vacío.
- Directorio de salida: `/` (raíz del repositorio).
